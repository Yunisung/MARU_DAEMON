# MARU_DAEMON

MARU_DAEMON은 결제·정산 업무를 자동화하는 Java 기반 데몬 도구 모음입니다. 다양한 배치 작업과 웹훅 처리를 담당하는 클래스들이 포함되어 있으며, 설정 파일과 쉘 스크립트를 활용해 운영 환경에서 동작하도록 구성되어 있습니다.

## 프로젝트 구조
- `src/com/pgmate/dm` : 정산, 계좌 조회, 웹훅, 배치 처리 등 주요 데몬 로직을 담은 Java 소스 코드.
- `conf/` : 데이터베이스 연결(`service.json`)을 비롯한 프로퍼티 및 로깅 설정 파일.
- `lib/` : 빌드와 실행 시 필요한 외부 라이브러리 JAR 모음.
- `bin/` : 배치 작업 실행용 쉘 스크립트와 Ant 빌드 스크립트(`build.xml`).
- `web/` : 웹 관련 리소스 및 테스트 자산.

## 필수 요구 사항
- Java 8 이상
- Apache Ant (빌드 스크립트 사용 시)

## 빌드 방법
Ant를 사용해 클래스 컴파일과 JAR 패키징을 수행합니다.

```bash
ant -f bin/build.xml
```

성공 시 컴파일된 클래스는 `classes/`에 생성되고, `lib/MARU_dm.jar` 파일이 만들어집니다. Ant 스크립트는 `lib/` 디렉터리 내 모든 JAR을 클래스패스로 사용합니다.

## 실행 예시
`com.pgmate.dm.main.Daemon` 클래스는 기본 통계 생성 작업을 수행합니다. 예를 들어 특정 날짜(YYYYMMDD)에 대한 작업을 실행하려면 다음과 같이 실행할 수 있습니다.

```bash
java -cp "classes:lib/*" com.pgmate.dm.main.Daemon TOT_CAP 20230101
```

인자가 없으면 현재 날짜 기준으로 기본 작업이 실행됩니다. 다른 배치 작업은 `bin/` 디렉터리의 쉘 스크립트를 참고해 적절한 클래스를 호출하세요.

## 구성 변경
운영 환경에 맞게 `conf/service.json`의 데이터베이스 연결 정보와 기타 프로퍼티 파일을 업데이트해야 합니다.
